# APLYD MSME platform

Status: documentation base. There is no application code yet, and nothing here is accepted for use with real factory data.

## What this is

A platform for Indian MSME manufacturers, built and owned by APLYD. The first product proposed in [docs/thesis.md](docs/thesis.md) is a readiness companion: a manufacturer enters its company profile once, and the platform maps that profile against a maintained rule book (export certification, medical-device regulation, quality systems) to show gaps, assemble the paperwork and hand hard questions to a human expert.

The proposal rests on the IndiaAI Mission MSME study (see [docs/sources.md](docs/sources.md)). It is a proposal, not a decision. The choices that are still open are in [docs/open-questions.md](docs/open-questions.md).

## Ownership

The platform is meant to be owned by APLYD, a separate organisation created by Athena Infonomics, and not by the client of the study it draws on. Until this repository is transferred to an APLYD GitHub organisation it sits under a personal account (open question OQ-01).

## Source material

The four study documents are not stored in this repository. [docs/sources.md](docs/sources.md) lists them with checksums so that anyone holding a copy can confirm it is the same file. The reason is open question OQ-09: the right to reuse study material has not been settled.
